# Shopify Theme Portfolio

Repositorio de demostración centrado en desarrollo de temas y componentes para Shopify. Incluye el tema de desarrollo completo en [`spectacular-focus-theme/`](./spectacular-focus-theme/) y el proyecto **Compra con confianza**, una sección de beneficios para fichas de producto que presenta información de envío, pago seguro y devoluciones.

## Tecnologías

Shopify Liquid, JSON de temas Shopify, HTML, CSS y SVG inline.

Consulta la documentación del componente **Compra con confianza** en [`portfolio/product-benefits/README.md`](./portfolio/product-benefits/README.md).

> Proyecto de demostración para portfolio; no representa una tienda en producción.
